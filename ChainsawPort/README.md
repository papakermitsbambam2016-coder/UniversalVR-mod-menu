# Chainsaw BONELAB Quest Port

Current-SDK reconstruction workspace for rebuilding the legacy TankFullOfOofs Chainsaw as a BONELAB standalone Quest spawnable.

- Target Unity: `2021.3.16f1`
- Target platform: BONELAB standalone Quest
- Current pallet reference: SDK `1.2.0`, pallet format version `2`
- Target pallet barcode: `TankFullOfOofs.Chainsaw`
- Target spawnable barcode: `TankFullOfOofs.Chainsaw.Spawnable.Chainsaw`

## Current reference

The uploaded `Frictic.DoomHunterChainsaw` Quest mod was inspected as a known-current chainsaw pallet reference. Its packed metadata confirms the shape we should target:

- pallet format version `2`
- `sdkVersion: 1.2.0`
- spawnable crate type `crate-spawnable#0`
- tags `Weapon`, `Melee`, `Blade`
- packed PreviewMesh + Spawnable + MonoScripts bundle layout
- Unity asset path for a normal Spawnable prefab

Reference metadata is stored under `CurrentReference/`. The DOOM Hunter assets themselves are not copied into this repository.

## Rebuilt project layout

Run these Unity editor commands once the current Marrow/compatible spawnable SDK is available:

- `Chainsaw Port -> Create Current SDK Migration Folders`
- `Chainsaw Port -> Create Chainsaw Prefab Skeleton`

The skeleton creates the hierarchy our companion code mod can recognize:

`Chainsaw -> GripPoint/GripCollider, Blade/BladeTransform/BladeCollider/slashTop/slashBottom/StabPoint, Audio/IdleSound/BladeAudio, Pull Cord, ImpactProperties, SoundsExt`

The body bounds are initialized from the recovered legacy Chainsaw metadata. The old model/material/audio assets still need to be assigned to this new prefab.

## Pallet template

`CurrentReference/Chainsaw.current-pallet-template.json` is a current-format template using the original Chainsaw barcode and current SDK `1.2.0` structure. The `mainAsset` and PreviewMesh GUID placeholders must be replaced by GUIDs generated by the reconstructed Unity project. The final pallet/catalog/bundles should be generated by the SDK's real **Pack for Quest** operation rather than hand-renaming files.

## Code-mod companion

The separate `Chainsaw BONELAB Code Mod` DLL is designed to recognize this hierarchy and add runtime blade/motor/damage behavior. Once this spawnable is actually packed for Quest, it can replace the temporary DOOM Hunter Chainsaw base.

## Chromebook / GitHub workflow

The repository can prepare and validate source files through GitHub, but the actual Marrow Quest bundle packing still requires a Unity editor environment with a valid Unity license and the compatible current SDK installed. The existing Unity workflow therefore should not be treated as proof of a valid spawnable until **Pack for Quest** succeeds and the result is tested on Quest.
