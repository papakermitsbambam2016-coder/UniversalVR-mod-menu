# Chainsaw Mod.io Version

This folder is the intended home for the final packed Marrow pallet.

The original uploaded release contains packed AssetBundles, not an editable Unity prefab/project. The current official MarrowSDK targets Unity 2021.3.16f1, but its latest README currently lists custom spawnables as unsupported. A verified current Quest pallet therefore requires a compatible custom-spawnable/extended SDK rebuild rather than simply changing pallet.json metadata.

Do not publish the legacy bundles as a verified current-version release until they have been tested in the target BONELAB build.
