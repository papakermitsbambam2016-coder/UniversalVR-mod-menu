# Reference DLLs

The code project expects target-build reference assemblies here when compiling:

- MelonLoader.dll
- BoneLib.dll
- Il2CppInterop.Runtime.dll
- UnityEngine.CoreModule.dll
- UnityEngine.PhysicsModule.dll

Do not substitute random versions. The DLLs must match the BONELAB/Quest build and loader environment being targeted.
